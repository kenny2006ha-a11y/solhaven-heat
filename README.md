Solhaven Heat is an original open-world crime game built for make.fun's "Make GTA 6" bounty. Explore the coastal city of Solhaven on foot or by car, steal vehicles, evade the police across a 0–5 star wanted system, and complete five story missions for Jack Rook, Mama Rosa and Eddie Vane.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD, drive with the car keys, press E to interact, F to shoot, P to pause, Q to save.
